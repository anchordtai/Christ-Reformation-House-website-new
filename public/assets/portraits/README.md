# Ministry portrait assets

These optimized WebP images were generated at the user's request from the user-provided portrait of Apostle (Dr) Anchord Taiwo. They are styled illustrations, not photographs documenting real services. The other person shown in the prayer scene is fictional. The user approved use of these pictures across the church website.

Placement:
- ministering-pink.webp: homepage teaching slide
- ministering-orange.webp: homepage prayer slide
- anchord-navy.webp: homepage senior pastor introduction
- anchord-cream.webp: About page leadership section
- anchord-charcoal.webp: Ministries invitation section
- anchord-black.webp: Contact page introduction

The homepage presents the portrait scenes with descriptive alternatives and a visible AI-created caption. Portraits are contained in the slider to avoid cutting off heads, hands, or feet. Formal portraits retain their original composition. Static images below the fold load lazily. All assets are hosted locally; the slider no longer depends on third-party stock photography.

Slider checks: previous/next, slide selection, keyboard arrows, pause/play, pause on hover and keyboard focus, hidden-tab suspension, and reduced-motion preference. Autoplay advances every seven seconds unless paused. Keyboard focus and manual selection pause rotation until explicitly played.

Before deployment, visually check the landing, About, Ministries, and Contact pages at 375px, 768px, 1024px, and 1440px widths. Automated interaction tests use a simulated DOM and do not validate browser layout. Existing prayer/contact/meeting API behaviour is outside this image integration change.
